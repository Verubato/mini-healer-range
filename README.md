# MiniHealerRange

Simple addon that shows a "no healer in range" red text warning message when out of range of your healer.

This is useful as in the heat of battle sometimes we lose track of our healer's positioning and so a simple big red text reminder can be helpful.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
